    evidence:
      - 7d08f3bd
  - title: Merge a pull request once its checks pass
    description: Turn on Merge when checks pass in the pull request popup above the message box. If GitHub can't hold the merge itself, for example when auto-merge is off for the repository, Threadlines waits until the checks pass and the branch is up to date, then merges while the app is running. The thread notes the result. When a merge isn't possible yet, the popup says why.
    evidence:
      - 845dac4e
      - "50206968"
  - title: Usage warnings come sooner
    description: Usage meters for Codex and Claude now turn amber at 75% and get redder as you near 100%, everywhere usage shows. Claude usage also has a "Use on claude.ai" link, since Claude's limit resets only work in Anthropic's own apps.
    evidence:
      - 7d08f3bd
  - title: Answer Codex tool requests in the thread
    description: Threadlines now supports Codex 0.155. When a Codex tool asks you to fill in a form or finish a step in your browser, the request shows above the message box so you can answer or decline it. If ChatGPT sign-in drops a thread's saved model, the picker says so and suggests another. And if the conversation is open in another Codex window, Threadlines asks you to close it there and keeps your messages.
    evidence:
      - 21b7d398
