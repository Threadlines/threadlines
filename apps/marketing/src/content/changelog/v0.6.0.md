  - title: Agents can start their own threads
    description: An agent can split a big job into new threads, each with its own worktree in a Git project, and pick up again as their answers come back. It asks you first unless you change that in Settings › Threads, and the new threads sit under their parent in the sidebar.
    evidence:

  - title: Guided setup for your agents
    description: First launch opens a setup that finds the agents already on your computer, installs and signs in to the ones you pick, and asks for a project folder. Settings › Providers now splits agents into In use and Not in use, and can add a second Codex, Claude, OpenCode or Antigravity account.
    evidence:
      - 18a5f7cd
      - 73bdecc2
      - 5e38874e

  - title: OpenCode 2, Google Antigravity and community agents
    description: OpenCode 2 and Antigravity install, update and sign in from Settings. Antigravity takes a Google account, Gemini Enterprise, a Gemini API key or Vertex AI (the last two bill per use). If you used OpenCode 1, turn it on in Settings › Providers, which shows how to move to 2. Providers also lists community agents from the open ACP registry, which we haven't tested, so each installs only after you confirm.
    evidence:
      - 66ef9cc2

      - 8d23e9e6
  - title: Connect a phone or computer with a short code
    description: Settings › Connections pairs a computer with a 6-digit code and a phone with a QR code. Devices paired this way are end-to-end encrypted, so the relay only passes along scrambled data, and each one can be removed on its own. Phones linked before 0.6.0 need to connect again.
    evidence:
      - 0b693a6c
