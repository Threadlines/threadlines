title: MCP apps show in the chat, and Claude tells you when it'll check back
summary: Tools that come with their own screen now show it in the chat, for Claude and Codex. Claude says when it'll check back on a thread, and you can cancel. Pi signs in from a list, the Mac Dock counts threads you haven't opened, and a streaming reply no longer redraws the whole chat.
githubRelease: https://github.com/Threadlines/threadlines/releases/tag/v0.7.1
highlights:
  - title: MCP apps show in the chat
    description: Some MCP tools have a small screen of their own, like a chart you can change or a form. With Claude and Codex, that screen now shows as a card under the step that ran it, and you can open it beside the chat. When the app wants to run one of its own tools, the card asks first. It skips asking only when the agent has full access, or after you pick Allow every call. Other agents' MCP calls still show as plain steps.
    evidence:
      - 6f0117d0
      - 18fdc4bd
  - title: Claude tells you when it'll check back
    description: When Claude schedules itself to come back to a thread, a line under the last turn says when, like "Checks back at 3:42 PM · in 14m", and why. The sidebar row counts down. Cancel ends that Claude session and every check-back in it, and asks first if work is still running. If the session or the app stops first, the chat says the check-back is gone. Jobs Claude saved to disk have no Cancel.
    evidence:
      - df425086
  - title: Sign in to Pi from a list
    description: Pi's Sign in no longer drops you into a terminal to type /login. Settings and the setup screen show a searchable list of what Pi can connect to, accounts first, like ChatGPT and GitHub Copilot, then API keys. Accounts open their sign-in page. Keys go in a password field, and Pi keeps them in its own folder. Pi's terminal sign-in is still there if you prefer it.
    evidence:
      - 6ffa5374
  - title: A streaming reply only redraws itself
    description: Each new chunk of a streaming reply used to redraw every message on screen. Now only the reply that changed redraws. In our test, 340 row redraws dropped to 20. Dragging a selection past the top of the chat now scrolls up while a reply streams. The Copy and Add note buttons follow their text as the chat scrolls.
    evidence:
      - 6563cf93
      - 982504cc
      - bedb4515
  - title: The Dock counts threads you haven't opened
    description: On a Mac, the red number on the Dock icon now matches the finished threads the sidebar shows as unread, including ones that finish while you're looking at another thread. It goes down as you open each one, on any device. On Windows, the taskbar's green done mark follows the same rule once nothing is running.
    evidence:
      - a07caca4
