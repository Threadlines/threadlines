It asks you first unless you allow it. You can also move a thread to another computer, set a project up there, and name each computer.

  - title: Agents outside Threadlines can start threads
    description: Claude Code, Codex, Gemini CLI or Cursor in your terminal can now start threads here and follow them, once you approve them in the app. You pick what each one may do, which projects it sees, and the highest access its threads get. Scripts can do the same with the new threadlines command, which the desktop app installs from Settings › Connections › Agents.

  - title: Scheduled and event tasks
    description: A task starts a thread on a schedule, like every weekday at 9, or when something happens, like a GitHub issue opening or a service calling its webhook. Agents can set tasks up too, and ask you first unless you allow them. Tasks run while Threadlines is running on that computer, and a time missed while it was off gets one catch-up run.
    evidence:
      - "58941803"
  - title: Alerts and swipes on your phone
    description: Your phone can now tell you when an agent needs you, finishes or fails, while it's connected to your computer through Connect a device. On an iPhone, add Threadlines to your Home Screen from Safari first. Swipe the sidebar and side panel closed, and swipe a thread to pin it or wrap it up, with Undo.
